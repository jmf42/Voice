# Skill Stack From Past Conversations

This stack is derived from local Codex history (`/Users/juanmanuelfontes/.codex/history.jsonl`) and should be the default for your repos.

## Default Skills To Apply

1. `repo-entrypoint-first`
Use first in every implementation task to find real entrypoints and constraints.

2. `brainstorming`
Use before creative feature work or behavior changes.

3. `test-driven-development`
Use for bug fixes and new features to lock expected behavior.

4. `systematic-debugging`
Use when there is a failing flow, regression, or unclear root cause.

5. `verification-gate`
Use before marking work complete (tests, lint, build where available).

6. `plain-english-engineering`
Use by default in explanations, because requests repeatedly ask for non-technical clarity.

7. `nondev-clarity`
Use in final handoff: what changed, where, how to run, and assumptions.

8. `proactive-delivery-playbook`
Use to implement end-to-end without waiting for unnecessary confirmations.
